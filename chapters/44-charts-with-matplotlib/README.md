# Chapter 44: Charts: A Spending Chart

How do you turn numbers into pictures with Python? In this chapter we use matplotlib to draw real charts, and you see each picture appear right after the code runs. We start with a bar chart of spending by category, add a title, labels and colours, switch to sorted horizontal bars with value labels, draw a balance line with markers and a grid, and combine two charts into one dashboard image. Everything is typed live and run for real, for Pocket Ledger.

## Files

- `charts.py`

## Run it

From this folder:

```bash
uv run charts.py
```

Tested with Python 3.15.1 and uv 0.13.5.
