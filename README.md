# Python From Zero: course code

Code for the **Python From Zero** video series (Python 3.15, run with [uv](https://docs.astral.sh/uv/)).

- `chapters/NN-title/`: the files typed in each video, exactly as they appear on screen.
- `pocket_ledger/`: the small spending tracker the series builds, piece by piece.

Run any chapter file with `uv run file.py`.
