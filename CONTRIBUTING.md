# Contributing

Thank you for helping to improve this course material.

- **Typos and small fixes**: open a pull request directly.
- **A chapter example does not run**: open an issue with your operating system, your `uv --version`, the command you ran, and the full error.
- **New practice exercises**: add them to the chapter README, keep them short, and make sure you have solved them yourself first.

Please keep the chapter files identical to what is shown in the videos. If a file needs a change to run on your system, describe the change in the chapter README instead.

By contributing you agree that your contribution is released under the MIT License.
